# Recall Desk

Permissions are scoped. Recall Desk makes enforcement scoped, too.

## What it is

Recall Desk enforces a scoped media-permission change across:

- Airtable — rights / permission registry
- Notion — live content
- Trello — planned editorial content

Core principle:

**The model interprets; code enforces.**
